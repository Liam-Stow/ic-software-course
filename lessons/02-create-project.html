By the end

You'll have an empty robot project, created from the Command Robot Skeleton template, open in WPILib VS Code.

Open the WPILib copy of VS Code you installed in the last lesson (it may say something like "2025" in the title). We'll use it to generate a fresh project to build on for the rest of the course.

Use these options

When the new-project form appears, fill it in like this (the Base Folder and Project Name can be whatever you want):

  • Project Type: Template
  • Language: C++
  • Template: Command Robot Skeleton (Advanced)
  • Base Folder & Project Name: your choice
Not the "Getting Started" example

The official instructions suggest the Getting Started Example. We do something different: we use the Command Robot Skeleton (Advanced) template instead. It gives us a clean, empty structure built around commands and subsystems — the way real IC robot code is organised.

? Which template should you pick for this course?
The Command Robot Skeleton gives us the command-based structure IC uses on real robots, which the rest of this course depends on.
What "command-based" means (preview)

Don't worry about the details yet, but the big idea is: we split the robot into subsystems (parts with motors and sensors) and describe what they do as commands (actions). You'll build your first subsystem in Module 1.
