Composing commands

By the end

One button will spin the flywheel, wait a second for it to get up to speed, then feed — all as a single combined command.

A flywheel needs a moment to reach full speed before you feed a ball into it — feed too early and the shot is weak. So instead of two separate buttons, let's combine the actions: spin up, pause, then feed, automatically.

Commands are composable

The real power of commands is that you can glue them together into bigger commands. Two of the glue functions:

  • .AlongWith(...) — run another command at the same time (in parallel).
  • .AndThen(...) — run another command afterwards (in sequence).

Build the composition

In RobotContainer.cpp, replace the A-button binding with this. Make sure #include <frc2/command/Commands.h> is near the top (the template usually adds it for you):

void RobotContainer::ConfigureBindings() { _controller.A().WhileTrue( SubShooter::GetInstance().SpinFlywheel() .AlongWith( frc2::cmd::Wait(1_s) .AndThen(SubFeeder::GetInstance().Feed()))); }
Reading it out loud

"While A is held: spin the flywheel, and along with that, wait 1 second and then feed."

The flywheel starts immediately and keeps spinning. In parallel, a one-second timer runs; once it finishes, the feeder kicks in — by which point the wheel is up to speed. 🎯

frc2::cmd::Wait(1_s)

Wait is a built-in command that simply waits for a set time. The 1_s is a unit — one second. WPILib uses units like _s, _ms, _deg and _rpm so the compiler can catch mistakes like mixing up seconds and milliseconds. You'll see lots more of these in Module 4.

Test it
  • Run the simulator and hold A.
  • The shooter speed jumps immediately.
  • After about a second, the feeder turns on too.
  • Release A and both stop.
? What's the difference between .AlongWith() and .AndThen()?
.AlongWith() = at the same time (parallel). .AndThen() = one after the other (sequence). Combining them lets you describe quite complex behaviour clearly.
? Why does the feeder wait a second before starting?
Feeding a ball into a flywheel that hasn't spun up yet gives a weak, inaccurate shot. The wait lets the wheel reach speed first.
