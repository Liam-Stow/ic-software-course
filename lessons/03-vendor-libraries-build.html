Vendor libraries & building your code

~10 min
By the end

You'll have installed the RevLib vendor library and seen your code BUILD SUCCESSFUL for the first time.

What's a vendor library?

To control hardware like a motor, we usually need code that the hardware's manufacturer provides. This is called a library or dependency. For this course we'll install just one: RevLib, from Rev Robotics. It lets us drive their Spark motor controllers, which IC uses a lot.

Install RevLib

  1. In the VS Code sidebar, open the WPILib Vendor Dependencies tab.
  2. Find REVLib in the list and install it with the blue button.

Build your code

To check the install worked, we'll build the project. Building converts your human-readable code into machine-readable instructions.

  1. Open VS Code's command palette with Ctrl + Shift + P.
  2. Run the WPILib: Build Robot Code command.
You're done when…
  • A terminal opens at the bottom of the screen and runs a build process.
  • It eventually prints BUILD SUCCESSFUL in green.
  • (This can take several minutes the first time — that's normal.)
? What does "building" your code actually do?
A build (also called compiling) translates the C++ you wrote into instructions a computer can run. If your code has certain mistakes, the build will fail and tell you where — a useful early warning system.
Build failed?

If you don't see BUILD SUCCESSFUL, read the red error text — it usually names the file and line with the problem. The most common cause at this stage is the Additional C++ install from Lesson 1 being skipped. Workshop mentors can help if you're stuck.

That's the whole setup done. From here on, it's all about writing code. 🎉
