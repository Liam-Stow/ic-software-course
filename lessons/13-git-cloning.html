Git & cloning the IC repo

By the end

You'll have Git installed and a copy of the team's real software project cloned to your computer.

What is Git?

Git is software that saves a history of versions of your code, lets the team share one project, and lets many people work on it in parallel without overwriting each other. Every serious software team uses it — and so do we.

Install Git

Grab it from git-scm.com/downloads. The installer has a lot of options — just leave them all at their defaults and click through.

Clone the IC project

"Cloning" means downloading a full copy of a project, complete with its history.

  1. Go to the ICRobotics GitHub page and open the latest software project repository (ask a mentor which one is current — e.g. the season's named project). If you don't have access yet, make a GitHub account and ask the team to add you.
  2. Click the green Code button and copy the HTTPS URL.
  3. Open WPILib VS Code to a folder where you keep IC projects. We usually use C:\scm\icrobotics (scm = "source code management"), but anywhere is fine.
  4. Open the command palette (Ctrl + Shift + P) and run Git: Clone.
  5. Paste the URL and press Enter.
Why clone the real project?

The team's project already contains helper code and tooling we'll use for the rest of the course (you'll copy some of it across in the next lesson). It's also how you'll contribute to the actual robot once you're up to speed.

? What does Git let a team do?
Git is version control: it tracks the history of your code and lets the whole team collaborate on one shared project without clobbering each other's work.
? What does "cloning" a repository mean?
Cloning pulls down the whole repository — files plus version history — so you can build and edit it on your own machine.
