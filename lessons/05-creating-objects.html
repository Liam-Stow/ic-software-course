Creating objects in C++

By the end

Your SubShooter will have a motor controller: a REV Spark Flex that can control a real motor.

How you make an object

Making an object in C++ means allocating a piece of computer memory to store data and functionality about a thing. To make an object, we need to write three things: the Type of the object, then a Name, then any inputs it needs. For example, making an object to represent a pen might look like this:

Pen myPen{"blue"};

This creates an object of the Pen type, called myPen, and gives it the word "blue" as an input. You might also hear this described as "constructing a Pen object" or just "making a Pen".

Types must already exist

A type has to exist in your code before you can use it. A few simple types come built in (integers, booleans, characters…), but many more types need to be included from somewhere first. The Spark Flex type lives in Rev's vendor library, so we include it.

Add the Spark Flex include

Near the top of SubShooter.h near the other existing include, add the rev/SparkFlex.h include so the SparkFlex type is available:

#pragma once #include <frc2/command/SubsystemBase.h> #include <rev/SparkFlex.h> ...

Construct the motor object

Lower down, under the private: heading, construct the Spark Flex. We'll name ours _shooterMotor:

private: rev::spark::SparkFlex _shooterMotor{1, rev::spark::SparkLowLevel::MotorType::kBrushless};
Reading the object
We just created a Spark Flex object:
  • It's type is rev::spark::SparkFlex.
  • It's name is _shooterMotor.
  • It has two inputs in curly braces:
    • The number 1 denotes that this Spark Flex has a CAN ID of 1. We use a CAN Bus to send signals to many of the devices on our robots, and every one needs a unique CAN ID.
    • The rev::spark::SparkLowLevel::MotorType::kBrushless input tells the Spark Flex that the motor attached to it is a brushless motor (rather than a brushed motor). In IC, we almost always use brushless motors.
Why is it under private:?

The motor object only needs to be used inside SubShooter — no other part of the program should poke at it directly. Keeping it private enforces that. You'll see the matching public: side in the next lesson.

? In SparkFlex _shooterMotor{1, ...}, what is the 1?
The first input is the CAN ID. Every device on the CAN bus needs a unique ID so the code can talk to the right one. (We'll tidy these IDs into Constants.h in Module 2.)
