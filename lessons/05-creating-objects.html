Creating objects in C++

Module 1 ~15 min
🎯

By the end

Your SubShooter will have a motor — a Spark Flex object that can control a real motor controller.

How you make an object

Making an object in C++ means writing three things: the Type of the object, then a Name, then any inputs it needs. For example, making an object to represent a pen might look like this:

Pen myPen{"blue"};

This creates an object of the Pen type, called myPen, and gives it the word "blue" as an input. You might also hear this described as "constructing a Pen object" or just "making a Pen".

Types must already exist

A type has to exist in your code before you can use it. A few simple types come built in (integers, booleans, characters…), but most useful types need to be included from somewhere first. The Spark Flex type lives in Rev's vendor library, so we include it.

Add the Spark Flex include

Near the top of SubShooter.h, add the highlighted include so the SparkFlex type is available:

#pragma once #include <frc2/command/SubsystemBase.h> #include <rev/SparkFlex.h>

Construct the motor object

Lower down, under the private: heading, construct the Spark Flex. We'll name ours _shooterMotor:

private: rev::spark::SparkFlex _shooterMotor{ 1, rev::spark::SparkLowLevel::MotorType::kBrushless};
Reading the two inputs
  • 1 is the CAN ID — the unique address of this motor controller on the robot's wiring. Each device needs its own ID.
  • kBrushless tells the Spark Flex that a brushless motor is attached (rather than a brushed one). In IC we almost always use brushless motors.
Why is it under private:?

The motor object only needs to be used inside SubShooter — no other part of the program should poke at it directly. Keeping it private enforces that. You'll see the matching public: side in the next lesson.
