Gear ratios & conversion factors

By the end

You'll command the turret in real degrees by teaching the Spark about the gearbox between the motor and the turret.

The turret motor doesn't drive the turret directly — it goes through a gearbox first, to make it stronger and slower. We'll use a gear ratio of 20:1: the motor spins 20 times for every 1 turn of the turret.

Note the gear ratio

Add a GEARING constant to the turret's private section in SubTurret.h:

private: ICSparkFlex _turretMotor{canid::TURRET_MOTOR, 60_A}; // Constants static constexpr double GEARING = 20;
Two ways to handle the gearbox

We need to convert turret degrees into motor revolutions.

  • Option 1: multiply by the ratio every time you set a target (angle * GEARING). Easy to forget somewhere.
  • Option 2 (we'll use this): tell the Spark a conversion factor once, and it does the maths automatically forever after. Cleaner and harder to get wrong.

Set the conversion factor in the constructor

In SubTurret.cpp, configure the encoder's conversion factors. We also set the PID gains here while we're at it:

SubTurret::SubTurret() { rev::spark::SparkBaseConfig config; config.encoder.PositionConversionFactor(1.0 / GEARING); config.encoder.VelocityConversionFactor(1.0 / GEARING / 60.0); config.closedLoop.P(0.1); config.closedLoop.D(0.1); _turretMotor.AdjustConfig(config); frc::SmartDashboard::PutData("Turret motor", &_turretMotor); }

Now TurnTo from last lesson stays simple — no multiplication needed, because the Spark converts behind the scenes:

frc2::CommandPtr SubTurret::TurnTo(units::degree_t angle) { return Run([this, angle] { _turretMotor.SetPositionTarget(angle); }); }
Why 1.0 / GEARING, not GEARING?

The Spark Max expects its conversion factor as input gear teeth ÷ output gear teeth, while WPILib's simulation objects expect output ÷ input — the inverse. So one of them has to be flipped. We invert here with 1.0 / GEARING. (The velocity factor also divides by 60 to convert per-minute into per-second.)

P = 0.1, D = 0.1

For position control a little D helps damp the motion so the turret doesn't overshoot and wobble. With no feedforward gains set, this is effectively a feedback-only controller — fine for a turret. You'll tune these live in the next lesson.

? What's the advantage of a conversion factor over multiplying by the ratio each time?
Set the factor once in the constructor and every target/reading is converted automatically. Manual multiplication has to be repeated everywhere and is easy to miss.
? With a 20:1 ratio, how many motor turns make one full turret rotation?
20:1 means the motor spins 20 times for each single rotation of the turret — that's what makes it stronger and slower.
