Functions & commands

~18 min
🎯

By the end

Your shooter will have a SpinFlywheel() command that spins the motor at 80% power while it runs, and stops it when it ends.

Functions

A function is a block of code that can be called to run later. You can spot functions by the ( ) parentheses at the end of their names. Every line inside a function's { } braces runs when the function is called.

Declare the command in the header

Under public: in SubShooter.h, declare a function called SpinFlywheel():

public: SubShooter(); void Periodic() override; frc2::CommandPtr SpinFlywheel();
Function → command

SpinFlywheel returns an frc2::CommandPtr (say "Command Pointer") — an action the robot can perform. Strictly, SpinFlywheel is a function that creates a command, but we usually simplify and just call it "a command". You'll run it on a button press soon.

Public vs private

Notice the motor object from last lesson is private, but SpinFlywheel is public. The motor doesn't need to be touched from outside the subsystem, but the command does — other code (the button bindings) needs to reach it. So it has to be public.

Define it in the body

Jump to SubShooter.cpp with Alt + O and fill in SpinFlywheel:

frc2::CommandPtr SubShooter::SpinFlywheel() { return StartEnd( [this] { _shooterMotor.Set(0.8); // On Start }, [this] { _shooterMotor.Set(0); // On End }); }
What StartEnd does

A StartEnd command runs one block of code when it starts and another when it ends. Here, on start we set the motor to 80% power; on end we set it back to 0%.

_shooterMotor.Set(0) makes the motor stay still; .Set(1) runs it at full power forward. In general, more power means faster spinning.

Always clean up

Setting the motor back to 0% on end is important — otherwise it would keep spinning after the command stops. A command should almost always "clean itself up" like this.

? The question from the guide: how would you make the motor spin backwards?
Power runs from -1.0 to 1.0. Positive spins one way, negative spins the other, and 0 stops it. So .Set(-0.8) spins backwards at 80%.
