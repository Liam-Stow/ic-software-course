Public, private & the Singleton

By the end

Your SubShooter will have a GetInstance() function, making it easy to reach from anywhere else in the program. The shooter subsystem will be complete!

We have one piece of housekeeping left before the shooter is done. Right now nothing outside SubShooter knows how to find it. Let's fix that.

Add GetInstance()

Jump back to SubShooter.h with Alt + O and add this function near the top of the public: section:

class SubShooter : public frc2::SubsystemBase { public: static SubShooter& GetInstance() { static SubShooter inst; return inst; } SubShooter();

This effectively turns our Subsystem into a Singleton. This is an in-depth topic, but for the purposes of our Starter Code example, it is simply helping us access our Subsystem from elsewhere in the program.

The Shooter Subsystem is now complete! It contains a Spark Flex motor controller and is capable of spinning and stopping. In the next section, we will look at how a human driver can operate this subsystem.

? What does the GetInstance() function help with?
The GetInstance function gives back the single instance of the SubShooter subsystem. This allows other code to access the shooter subsystem without creating a new instance.
