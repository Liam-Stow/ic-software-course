Installing WPILib and its tools

By the end

You'll have WPILib VS Code installed, the tool you need to write, build and simulate FRC robot code.

Throughout this course you'll build a mock robot program that solves common FRC problems: a shooter, a feeder, a turret and a climber. None of it runs on a real robot, everything runs in simulation on your own computer.

What is WPILib?

WPILib is the official software library and toolset for FRC. The installer gives you a special copy of VS Code (a code editor) that already knows how to build robot code, plus the simulator and other tools. We use a separate copy so it never clashes with any normal VS Code you might already have.

Install it

Follow the official WPILib install instructions for your operating system: WPILib installation guide. While running the installer, choose Everything as the install mode and click Install for all Users.

Don't stop early

On the install page, scroll down a little further and also complete the Additional C++ Installation for Simulation step. It's easy to miss.

? Why do we install a separate copy of VS Code through the WPILib installer?
The WPILib copy comes pre-loaded with the FRC build tools, simulator and extensions, and stays isolated from any other VS Code you have. Regular VS Code can edit C++ too — it just wouldn't be set up to build robot code out of the box.
